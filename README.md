# club-kit

Tools a student organization can use to run events and keep track of members. Built by LITSA at Suffolk Law
from what we needed for our own events, and written so other clubs can reuse it.

## What's here

| Folder | What it does | Status |
| --- | --- | --- |
| [`docs/event-checklist.md`](docs/event-checklist.md) | Every step for a Suffolk Law student-org event, with deadlines | Ready |
| [`docs/rsvp.md`](docs/rsvp.md) | An RSVP form plus a short link you can print and change later | Ready |
| [`qr/`](qr) | Make a print-quality QR code for any link | Ready |
| `flyers/` | Event flyers in Instagram, story, letter, poster and TV sizes from one script | Planned |
| `newsletter/` | An email newsletter template that survives Outlook | Planned |
| `roster/` | Turn sign-in sheets into a clean member list and reconcile it with your mailing list | Planned |

The planned pieces have open issues. Pick one up.
